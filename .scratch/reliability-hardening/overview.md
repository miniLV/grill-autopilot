## D 验证边界
```flow LR
一次skill运行 -> Git与worktree状态
一次skill运行 -> Ticket状态
一次skill运行 -> 最终brief
```
| 证据层 | 能证明什么 |
| --- | --- |
| 文档契约核对 | 各场景的规则完整且一致 |
| 临时 Git 实验 | 分支、文件保存和回滚语义 |
| 真实模型试运行 | 指定 runtime 的实际行为 |
Git 实验通过，不能替代完整流程通过。
